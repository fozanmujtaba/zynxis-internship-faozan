### Week 4 — RAG for Agents

**Deliverables:** Agent interaction logs + Final generated report

**Deliverables:** Security Agent script + Analysis screenshots

### Week 7 — Autonomous Business Logic

**Deliverables:** Implementation code + Example Task Plan output
